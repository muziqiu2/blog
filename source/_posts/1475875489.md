PicX 的图床服务依赖 GitHub Token，在开始使用之前，你必须先 **[创建](https://github.com/settings/tokens/new)** 一个带有 `repo` 权限的 GitHub Token。

点击 [https://github.com/settings/tokens/new](https://github.com/settings/tokens/new) 快速新建 GitHub Token

![](https://vip-img.mofashi.ltd/2/2023/11/17/65573f43ea9c5.png)

点击 **`Generate token`** 按钮，生成 GitHub Token。

![](https://vip-img.mofashi.ltd/2/2023/11/17/65573f7e5f165.png)

![](https://vip-img.mofashi.ltd/2/2023/11/17/65573f803ba5d.png)

> 注意
> 
> **新生成的 Token 只会显示一次，请妥善保存，如有遗失，重新生成即可。**

## [](#配置图床 "配置图床")配置图床

### [](#一键自动配置 "一键自动配置")一键自动配置

填写 GitHub Token，点击 **`一键自动配置`** 按钮会自动创建 GitHub 仓库，并完成仓库、分支和目录之间的绑定。

> -   自动创建仓库：`picx-images-hosting`
> -   自动创建分支：`master`
> -   自动创建目录：`yyyyMMdd` (当天日期，例如：`20230403`)

**如果你是第一次使用 PicX，那么推荐使用一键自动配置，非常方便**。当然你也可以随时切换成手动配置。

![](https://vip-img.mofashi.ltd/2/2023/11/17/65574050933b5.png)

### [](#手动配置 "手动配置")手动配置

对于 PicX 的老用户，或者你准备使用一个已有的 GitHub 仓库做图床，使用手动配置更为灵活。

![](https://vip-img.mofashi.ltd/2/2023/11/17/65574050900e8.png)

## [](#上传图片 "上传图片")上传图片

### [](#选择图片 "选择图片")选择图片

-   可以通过 **拖拽图片** 到上传区域进行上传。
    
-   可以通过 **复制图片**，然后 **粘贴** 到上传区域进行上传。
    
    > 粘贴图片快捷键 **`Ctrl + V`** 或 **`Command + V`**
    
-   可以通过点击上传区域，通过 **选择文件** 的方式选择需要上传的图片。
    

![](https://vip-img.mofashi.ltd/2/2023/11/17/655740cf9dd52.png)

### [](#上传图片-1 "上传图片")上传图片

点击 **`上传`** 按钮或使用 PicX 提供的快捷键 **`Ctrl + S`** 或 **`Command + S`** 进行上传图片。

![](https://vip-img.mofashi.ltd/2/2023/11/17/65574100502b0.png)

### [](#复制图片链接 "复制图片链接")复制图片链接

图片上传成功后，PicX 会自动复制图片链接到系统剪贴板，你也可以手动点击 **`复制图片链接`** ，然后通过快捷键 **`Ctrl + V`** 或 **`Command + V`** 粘贴使用。

![](https://vip-img.mofashi.ltd/2/2023/11/17/6557412bd8c9c.png)
